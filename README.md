# Quiz Web Application 🎯

## 🔹 Description
An interactive quiz web application built using Python and Streamlit.
Users can answer questions and view score-based visualizations.

## 🔹 Tech Stack
- Python
- Streamlit
- ngrok
- Matplotlib

## 🔹 Features
- Multiple-choice quiz
- Score calculation
- Graph-based result visualization
